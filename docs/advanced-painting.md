# Advanced native painting controls

The implemented extension follows OrcaSlicer 2.4.2 commit `8500fcdccaa10b5099ac20d252af3a7c560046f1`. Circle uses a view-direction projected cylinder and front-facing connected facets. Sphere traverses connected intersecting facets without a backface filter. Native brush radius is 0.4–8 mm; default boundary detail is 0.05 mm. A custom coarser detail remains available. Smart fill follows source-normal adjacency at 0–90 degrees. Bucket fill follows touching leaf subfacets of the same existing state, optionally stopping at sharp edges. Triangle selects the current leaf subfacet; Original triangle explicitly replaces all of its subdivisions.

Height-range color painting uses world Z. View clipping filters rendered model/paint surfaces and ray hits, and constrains edits to the retained halfspace. Support tools highlight overhangs, constrain strokes to highlighted normals, and select complete overhang facets using the native inverse-transform angle comparison. Gap fill builds same-state connected patches, measures source-mesh area, and replaces patches strictly smaller than 0–5 square millimeters with the smallest neighboring state. All patch decisions use the pre-edit snapshot, so adjacent small regions can exchange states in one pass, as native code does.

Leaf adjacency matches partial collinear edge intervals, preserving neighbors across unequal native subdivisions. Connectivity work is bounded to 200,000 source/leaf facets and 2,000,000 overlapping edge comparisons; excessive or ambiguous geometry fails without changing the model. Original-triangle editing remains available on larger valid models.

Primary sources: [TriangleSelector](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/libslic3r/TriangleSelector.cpp), [painter base and gap patches](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/slic3r/GUI/Gizmos/GLGizmoPainterBase.cpp), [native brush limits](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/slic3r/GUI/Gizmos/GLGizmoPainterBase.hpp), [support-angle selection](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/slic3r/GUI/Gizmos/GLGizmoFdmSupports.cpp).

Five new unit tests pass alongside thirteen existing painting tests. Three additional real native tests compare generated output to independent configurations: all 400 outer-wall paths and material slots from height painting equal native height-range extruder overrides; a 7.99 mm second-material island disappears after gap fill and all 400 outer-wall paths equal an unpainted reference; overhang-angle selection produces exactly the same 1,207 support deposition paths as explicit downward-face annotations.

This does not claim complete native GUI parity. Circle/sphere capsule strokes and one-pixel screen-ray interpolation now have three additional unit tests, one installed-native test and one browser test; see [continuous painting](continuous-painting.md). View-aligned clipping and display caps are covered separately in [painting view and inventory](painting-view-and-inventory.md). Remaining source-confirmed work includes manual filament remapping, cursor graphics and real support preview. No generic automatic color-painting command was found in the pinned segmentation editor. Native GUI re-export remains unverified.
