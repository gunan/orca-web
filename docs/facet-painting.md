# Native facet painting

Orca Web preserves and edits OrcaSlicer 2.4.2 support, seam, filament color and fuzzy-skin facet annotations. Sphere strokes refine the actual triangle into native midpoint subfacets. Original-triangle painting replaces an original triangle's existing subdivisions in that channel. Connected-surface fill follows edge adjacency and the selected maximum adjacent-normal angle. The viewport overlays those exact decoded subfacets; source mesh triangles remain unchanged.

Support enforcers require support enabled (manual support generates painted enforcers). Fuzzy paint is sliced with the native Painted only (`fuzzy_skin=none`) or another enabled fuzzy mode. Painting does not automatically change process settings. The native facet state encoding supports filament slots 1–16; other project material workflows can expose more slots.

The implementation follows pinned native source commit `8500fcdccaa10b5099ac20d252af3a7c560046f1`:

- [`TriangleSelector` serialization and subdivision](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/libslic3r/TriangleSelector.cpp): native tree child order, midpoint positions, one/two/three-edge subdivisions and state encoding.
- [`FacetsAnnotation` nibble order](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/libslic3r/Model.cpp): reversed hexadecimal storage.
- [`bbs_3mf` annotations](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/libslic3r/Format/bbs_3mf.cpp): `paint_supports`, `paint_seam`, `paint_color` and `paint_fuzzy_skin` triangle attributes and retained component transforms.

`mesh.painting` is sparse JSON: `{version:1,winding:1,supports:{triangleIndex:'4'},seam:{...},color:{...},fuzzy:{...}}`. Raw native strings are retained. The explicit winding can be -1 because two-edge native subdivisions have an asymmetric diagonal; swapping triangle vertices cannot generally preserve that boundary with midpoint subdivisions. A mirrored export retains the tree and uses a mirrored 3MF component transform. This composes with the centered object/build frame used by native brim ears.

Validation bounds hexadecimal length, tree depth, aggregate nodes, index range and native state/filament limits. The archive safety gate checks malformed annotations before raw 3MF reaches the native engine. Project parsing and sanitized project slicing also validate painting. Painting helper volumes is rejected because their native semantics do not support this editor. Rigid transforms, positive scale, place-on-face and duplicates retain facet correspondence; reflection toggles winding. Split, assembly and disassembly remap original facet indices; repair retains unambiguous painting and rejects painted facet deletion or incompatible reflected subdivision bases. Cut and regenerated text require explicit clearing consent before applying changed topology.

Acceptance evidence: thirteen unit/service tests cover native encoding, malformed inputs, exact mirrored regions, brim-frame composition, saved JSON validation and geometry operations. Three real 2.4.2 slicing tests pass through the sanitized project service. Six browser regressions cover real raycast editing, exact overlays, native export, undo, geometry preservation, and explicit paint-loss consent. Manual support grows from zero to 1,207 deposition segments; 100 layer seam starts move from X<1 to X>19; painted-only fuzzy skin grows from 400 to over 5,000 outer-wall segments on the selected side; color paint consumes two actual material slots. A mirrored asymmetric two-edge facet produces exactly the same 296 second-filament wall segments and filament consumption as an independently transformed native archive.

This is a partial painting milestone. Subsequent work adds circle strokes, native leaf/bucket/smart fill, support-angle constraints, height paint, gap fill and continuous stroke interpolation; evidence is in [advanced painting](advanced-painting.md) and [continuous painting](continuous-painting.md). [The source-backed control inventory](painting-view-and-inventory.md) separates implemented behavior from manual filament remapping, brush cursor graphics, support preview and remaining native GUI acceptance. Native project import/export must be used to preserve engine paint attributes; plain STL contains geometry only.
