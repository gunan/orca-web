# Painting view and native control inventory

Pinned reference: OrcaSlicer 2.4.2, commit `8500fcdccaa10b5099ac20d252af3a7c560046f1`. The source-backed controls below are separate acceptance units; they are not a claim that the entire native painting interface is complete.

| Control | Pinned source | Acceptance and current evidence |
|---|---|---|
| Circle, sphere, triangle and continuous strokes | `GLGizmoPainterBase::get_projected_mouse_positions`, `TriangleSelector::select_patch`, `Capsule2D`, `Capsule3D` | Exact decoded leaf region matches rendered paint; sparse strokes have no gaps; source triangles stay unchanged. Unit, browser and native material-strip evidence exists. |
| Smart fill | `TriangleSelector::seed_fill_select_triangles` | Connected source-normal angle boundaries match the native 0–90 degree rule. Unit/browser cases exist. |
| Bucket fill and edge detection | `TriangleSelector::bucket_fill_select_triangles` | Adjacent same-state leaves, including unequal subdivisions, respect optional normal-angle boundaries. Unit/browser cases exist. |
| Gap fill | `TriangleSelectorPatch::update_selector_triangles` in `GLGizmoPainterBase.cpp` | Local-area patches below threshold choose lowest adjacent state using a snapshot. Unit/browser and independent native material-path evidence exists. |
| Height color paint | `GLGizmoMmuSegmentation` HeightRange and `TriangleSelector::HeightRange` | Edited world-Z interval slices like independent native height-range extruder settings. Unit/browser/native evidence exists; pointer-start height cursor and browser behavior are now implemented and tested. |
| Clipping position and Reset direction | `ObjectClipper::set_position_by_ratio` in `GLGizmosCommon.cpp` | Normal is opposite camera forward; 0–1 moves through the bounding sphere; orbit does not rotate an already fixed plane, Reset does. The browser uses world bounds center for arbitrary source coordinate conventions. Three cap/view unit tests pass. The new browser test and all ten prior painting cases pass against the integrated build. |
| Clipping caps and outlines | `ObjectClipper::render_cut` | Actual mesh-plane intersections render gray fill and white contours, retaining holes and disconnected shells. Generated display caps never become painted source facets. Unit tests cover area, holes, winding, transforms, on-plane edges and open-contour rejection. |
| Brush cursor graphics | `GLGizmoPainterBase::render_cursor_circle`, `render_cursor_sphere`, `render_cursor_height_range` | Radius/height graphics follow the actual world hit and camera projection. Two unit cases and one browser case pass; see painting-cursors.md. |
| Remap filaments / Reset | `GLGizmoMmuSegmentation::render_filament_remap_ui` (991), `remap_filament_assignments` (1082) | Source slot → destination slot mapping changes native leaf states and base volume/object fallback extruder while preserving geometry and other channels. Mapping Reset cancels pending remap; applied remap is undoable. Two unit cases, one browser case and an exact 1,305-wall-path native comparison pass; see filament-remapping.md. This is manual mapping, not a discovered automatic color-paint command. |
| Support by angle and highlighted-only painting | `GLGizmoFdmSupports::select_facets_by_angle` | Native inverse-transform angle rule and world-normal stroke constraint. Unit/browser and identical 1,207 native support paths verified for the recorded fixture. |
| Support preview | `GLGizmoFdmSupports` calling `PrintObject::generate_support_preview` | Real native support geometry reflects current support annotations/settings. Pending; an orange overhang highlight is a different feature. |

Primary sources: [painter base](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/slic3r/GUI/Gizmos/GLGizmoPainterBase.cpp), [triangle selectors](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/libslic3r/TriangleSelector.cpp), [clipping](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/slic3r/GUI/Gizmos/GLGizmosCommon.cpp), [filament remapping](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/slic3r/GUI/Gizmos/GLGizmoMmuSegmentation.cpp), [support tools](https://github.com/SoftFever/OrcaSlicer/blob/8500fcdccaa10b5099ac20d252af3a7c560046f1/src/slic3r/GUI/Gizmos/GLGizmoFdmSupports.cpp).

Clipping is display-only. It does not change triangles, native facet strings or sliced output. Cap work is bounded to two million input triangles, 200,000 intersecting/plane edges and 2,048 closed contours. Open or ambiguous sections show an explicit warning instead of fabricated fill. The browser screenshot shows the actual gray cross-section and white boundary. Native GUI screenshots/re-export and full keyboard/right-button equivalence remain unverified while GUI access is blocked.
