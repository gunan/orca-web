# Native brim ears

The Brim ears editor adds, moves, resizes and removes manual adhesion points on a selected object. It selects the native `painted` brim type for that object, preserves draft cancellation, and applies changes as one undo step. Coordinates shown in the dialog are plate coordinates. Prepare renders the actual stored centers and radii as translucent circles; Preview contains the native deposited paths. Native line spacing, brim gap and elephant-foot compensation determine the final path boundary.

Sparse `object.brimEars` data stores centers in an anchor part's source frame and a radius in millimetres. Whole-object transformations move the centers while retaining diameter, matching native instance scaling. Part edits retain object-level world positions; duplication of an individual part does not duplicate ears. Deleting the anchor part transfers its points to another normal part. Mirror reflects the centers; cuts and topology-changing split/repair operations clear incompatible ear metadata.

`Metadata/brim_ear_points.txt` uses native format version 0 and 1-based model-object indices. Import maps build instances and plate offsets. Export centers objects that contain ears, writes geometry and ears in that frame, then places the build instance. This is necessary because the native importer recenters volume geometry without applying that recentering to auxiliary points. Bounds include 1024 points per object, finite coordinates, positive radii up to 1000 mm, unique indices, complete records and the supported version.

Four unit cases cover malformed data, indexed multi-plate round trips, transforms, mirrored centers, part edits and deletion. An installed 2.4.2 test produces 110 left-ear and 109 right-ear adhesion segments in their respective corner regions. The same test produces no adhesion without points or with points above the bed. Browser tests cover real marker coordinates, native export, cancel, validation, undo/redo and removal. A separate browser/native test slices the edited ordinary model with installed presets and checks the deposited adhesion region.

The first native probe exported points in an uncentered frame and produced no adhesion. That failed probe led to the centered export above. An initial browser export test also failed because its generic fake preset intentionally contains an ambiguous scalar speed; the ordinary browser test now imports the valid native preset fixture, and the browser/native test exercises installed catalog presets directly.

Interactive native brush placement, drag handles, native automatic ear detection and full GUI comparison remain incomplete. Ears above Z=0 are retained and visibly warned about; native slicing ignores them. No printer has been contacted.
