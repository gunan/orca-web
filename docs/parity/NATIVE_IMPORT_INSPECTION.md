# Native geometry import inspection

This staged implementation uses the pinned original OrcaSlicer2.4.2 Model and TriangleMesh methods to inspect structured Orca/Prusa3MF geometry before multipart detection and placement. `ModelObject::get_object_stl_stats`, `Model::removed_objects_with_zero_volume`, `looks_like_saved_in_meters` and `looks_like_imperial_units` run inside the existing bounded native geometry worker. The adapter constructs native volumes and all instances from retained indexed coordinates and separate volume/build transforms. It does not estimate native volume in JavaScript.

A model with native volume strictly below1e-10 is removed as a complete family, including all visible instances and parts. The source information icon and text are shown before the surviving geometry is committed. Add remains one Undo action. Cancellation, parser/worker failure and all-empty results preserve the current document. Project/settings loads do not enter this geometry-only path.

The native statistics retain float accumulation, count only normal volumes, and use the absolute volume/first-instance determinant. Later instances do not multiply the model volume. Cut identity/checksum/connector relations affect imperial inference. Meter/inch classification is returned for subsequent unit-conversion work; those prompts are not implemented by this milestone.
