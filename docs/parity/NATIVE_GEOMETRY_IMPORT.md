# Native geometry-only import

Orca and Prusa project geometry now passes through the existing validated project importer, retaining individual volumes, negative/modifier/support roles, linked instances, printable flags, exact indexed mesh frames, four painting channels, variable-layer profiles/ranges, text/SVG editing metadata, brim attachments and processed cut relations. Imported global presets, plate events and project assets are not adopted. Native object/volume overrides are reset except extruder; a missing or zero object extruder becomes1. Material assignments and painting grow the current material slots. Current material colors and purge tables survive geometry-only Open.

Source plate origins are restored before combining geometry on the active plate. Native normal-part bounds drive centering; outside modifiers do not move the solid. Retained indexed coordinates avoid the viewport Float32 transform path. Model families remain linked within each import and receive independent identities across repeated imports. Native role sorting places blockers before enforcers. First-instance minimum Z and auto-drop flags follow the two native ensure-on-bed calls around centering. Geometry Add is one Undo transaction; Open replaces the scene after its existing discard handling. Cancellation or parser failure leaves the current document/history intact. Import size and existing project limits remain enforced.
