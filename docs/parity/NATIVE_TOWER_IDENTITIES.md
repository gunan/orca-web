# Collision-safe native tower identities

Baseline: installed OrcaSlicer 2.4.2, source `8500fcdccaa10b5099ac20d252af3a7c560046f1`.

The preview adapter previously used an instance-family token and an unrelated standalone object's serialized plate/group key in the same map namespace. A legal collision merged two native models, losing the second model's material, settings and geometry. A two-material tower could disappear. Valid long or escaped plate/group IDs could also exceed the worker's 256-byte name bound after composition; multibyte family/group names could fit the JavaScript character bound but exceed the native byte bound.

Family and standalone map keys now use separate tagged namespaces. The adapter preserves short unique transport names and deterministically allocates bounded ASCII worker names when a composite/UTF-8 name is too large or collides. Allocated names avoid existing user family tokens. User IDs, family membership, project insertion order and native instance-zero collection semantics remain unchanged. No native kernel or golden geometry was modified.

All eight final identity fixtures pass project validation and fail against the unchanged preceding adapter in an isolated diagnostic. The corrected adapter passes eight unit cases and eight native comparisons against the original two-material tower reference. Earlier focused native validation passed 64 checks (seven new identities plus all existing tower/Fill reference checks); the later eighth case and its valid selected IDs pass in the final 16-check unit/native run. Two browser/API/native-worker cases verify both materials remain visible and saved user IDs/families remain intact. The complete unit/API suite passes 986 tests; the production build and full 290-test browser suite pass. Full native:305 passed,one strict reference-input repeatability failure. Full native-browser:73 passed,one diagnosed Preview job-clear crash. See [complete M30 results](MILESTONE_30.md).

[Final old-adapter failures](TOWER_IDENTITIES_BEFORE_M30.log), [final eight-case unit/native checks](TOWER_IDENTITIES_FOCUSED_M30.log), [initial broad native checks](TOWER_IDENTITIES_NATIVE_INITIAL_M30.log), and [native browser results](TOWER_IDENTITIES_BROWSER_M30.log) are retained. The first browser fixture mistakenly added a catalog filament before enabling embedded settings, leaving only one embedded slot; it timed out waiting for a correctly suppressed tower request. The corrected fixture enables embedded settings first and asserts its second slot. A cancelled test left its isolated server running; the identified test process was stopped before the final run. Neither failure changed production material logic.

Active plate identifiers still retain the worker's own bounds, and larger payload/geometry limits remain enforced. Custom fractional plate sizing, post-slice towers, direct tower gizmos, native GUI/hardware acceptance and earlier motion-repeatability/Preview-idle failures remain open. These feature units remain partial.
