# Native preview ranges and stationary events

This change follows OrcaSlicer 2.4.2, revision `8500fcdccaa10b5099ac20d252af3a7c560046f1`. It extends `preview.playback`, `preview.layers`, `preview.toolpath`, `preview.legend`, and `preview.gcode`; these broad features remain partial.

Original native vertex IDs drive the horizontal slider. Consecutive vertices sharing a G-code line form one tick, including arc and acceleration subdivisions. Hidden travel, wipe, and stationary events remain within the native range. Stationary events can be inspected without inventing a spatial segment. Vertex order is preserved even when the native options Z corrector reorders events relative to source lines.

Top-layer-only playback defaults to enabled, as in native AppConfig. During partial playback, lower selected layers remain visible in native dark gray (`64,64,64`); the full endpoint restores normal colors. Full, enabled, and visible ranges are distinct. Visibility changes preserve the native clamping order and existing partial range. Enabling an earlier retraction during partial all-layer playback does not add that earlier event to the visible range.

Nine motion/event visibility controls are independent. Seams default to visible; the other options default to hidden. Seven stationary event types render the native 16-sided paired-cone template, with 32 triangles per instance. Geometry is generated by compiling original `OptionTemplate::init`, replacing only GPU upload with data capture. The native shader retains lighting, the half-height offset, platform scale (0.75 on macOS; 1.5 elsewhere), and eye-space bias. Native events with zero dimensions remain degenerate rather than receiving invented dimensions.

Preview Cmd/Ctrl+G and Shift+G open **Jump to Layer** before global export handles the key. The dialog accepts only decimal digits within one-based layer bounds, moves the active layer thumb, honors single-layer mode, and supports Enter, Cancel, and Escape. Editing fields and other modal dialogs retain their keys. Native's horizontal slider exposes only a high thumb (`IMSlider::render`); its retained low endpoint is internal state.

## Evidence

- **94 compiled original C++ cases** compare full/enabled/visible ranges, segment/event IDs, and hidden/grouped ticks. Cases cover each option, hidden roles, partial-range transitions, all-hidden cases, bounds, and spiral extensions. The facade compiles original `Range.cpp`, `ViewRange.cpp`, `PathVertex.cpp`, `Types.cpp`, extracted `ViewerImpl` methods and `GCodeViewer::update_moves_slider`; only GUI/OpenGL output sinks are substituted.
- **Seven genuine GUI-file captures** compare complete native segment/event/tick lists by count and SHA-256, plus exact ranges. The existing `native-gui-shrink98-2.4.2.gcode` fixture remains the single retained copy. Through layer 50, the top-layer enabled range is vertices **13240–13379**.
- A second real-worker test processes all seven event types using the genuine file's native configuration with two declared materials. It checks the native Z-corrector ordering: a tool change on source line 23 precedes a custom event on line 22 in vertex order. These are parser inputs; no firmware command is sent to a printer.
- Browser transform feedback compares **3,456 position/color values** with original native GLSL over all 96 template vertices, both platform scales, multiple dimensions, and a zero-size case. Reference transport substitutions replace unsupported texture-buffer fetches with attributes. Reference coordinates remain native and receive the equivalent native-to-web view matrix.
- **11 unit + 2 native tests, 20 source/fallback browser tests, and 6 native-preview browser tests pass.** New cases contribute 7 unit, 2 native, 2 browser, and 2 native-browser tests. The rest are existing regressions. The production build passes.
- Screenshot review found and fixed native timing/material text squeezing feature names into character-sized columns. A positive capture is retained in the isolated acceptance output under `test-results/range-native-browser/.../native-event-markers.png`.

One initial browser expectation incorrectly included an earlier newly enabled retract before the retained partial range. The native oracle showed that it remains excluded; the final assertion explicitly checks this. Another initial assertion assumed every native event had dimensions. The native initial tool change has zero dimensions; the final test requires those zeroes.

The generators verify the pinned Git revision and reject tracked source modifications. Fixture generation uses the installed C++ compiler; normal web tests use committed fixtures and add no dependency.

## Remaining scope and limits

This is source/worker/browser acceptance, not a completed native GUI visual comparison. The locked desktop has not been used to certify this integration. Source-only fallback retains spatial-command behavior and does not invent native hidden events or timing. Travel/wipe tubes, native tool-head/center-of-gravity markers, additional color modes, native legend/event statistics, slider layout, and pixel-level parity remain separate work. Layer custom-code editing, firmware execution, and physical printer verification are not added here.

Worker limits remain unchanged: 25 MB input, 500,000 render vertices, bounded worker output, and bounded raw inspector windows. Controls validate layer indices and vertex bounds. The port guards a degenerate spiral predecessor at zero rather than reproducing native unsigned underflow; all valid reference cases follow native behavior.
