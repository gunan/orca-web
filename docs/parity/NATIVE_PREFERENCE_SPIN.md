# Native preference numeric controls

FPS now uses the native left-hand arrow placement and unchanged installed spin_inc/spin_dec SVGs, an editable text field and an inline FPS suffix. Pressing an arrow applies one immediate step from the committed value. Holding waits400ms, then steps every100ms. Release selects the text; pointer capture keeps the hold active outside the button. Release, lost capture, input/window focus loss, page hiding and dialog disposal cancel repetition. Queued callbacks maintain their own current committed value so React batching cannot lose increments.

Keyboard arrows operate on the current numeric draft and honor native boundaries. Orbit speed is now a plain text field, matching create_camera_orbit_mult_input rather than adding browser number spinners. Neither field adds wheel stepping. The native SpinInput wheel method exists but its event-table binding is commented out. Existing visible web validation remains; invalid-text behavior is not declared native-identical.
